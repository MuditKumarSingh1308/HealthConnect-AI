# Changelog

All notable changes to HealthConnect AI will be documented in this file.

## 0.1.0 - Hackathon MVP

### Added

- Next.js, TypeScript, Tailwind CSS frontend.
- FastAPI backend with modular API routers, schemas, and services.
- Premium landing page with Demo Mode.
- Mock authentication pages.
- Patient dashboard.
- AI Command Center for emergency action plans.
- Rule-based emergency triage.
- Smart hospital recommendation.
- Ambulance booking and simulated tracking.
- Blood bank finder and emergency request flow.
- Medical report explanation module.
- Government scheme assistant.
- Branding system with logo, favicon, loading screen, 404 page, About page, and Contact page.
- Professional README, license, and contribution guidelines.

### Notes

- Current data is mock-only.
- Current AI behavior is deterministic and rule-based.
- PostgreSQL, real authentication, and external AI providers are planned for future versions.
